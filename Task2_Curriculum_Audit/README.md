# Task 2 — AI/ML Curriculum Audit

## Overview

This folder contains a preliminary audit of the B.Tech in Artificial Intelligence and Machine Learning curriculum, based on the available IcfaiTech Student Handbook 2023–24 extract, selected industry job descriptions, and an AI-assisted subject review.

## How to Review

1. Start with `report/01-curriculum-baseline.md` for the handbook-based curriculum summary and credit audit.
2. Read `report/02-industry-job-analysis.md` for the selected job-description analysis.
3. Read `report/03-curriculum-recommendations.md` for KEEP, UPDATE, REDUCE, and ADD recommendations.
4. Review `report/04-ai-subject-review.md` for the AI-assisted subject analysis and prompts.
5. Read `report/05-revised-curriculum.md` for the proposed curriculum changes.
6. Read `report/06-capstone-proposal.md` for the proposed capstone.
7. Finish with `report/07-final-audit-report.md` for the consolidated findings.

## Credit Calculator

Open `tools/credit-calculator.html` in a web browser. The calculator illustrates the 20% planning target. It does not determine or approve official programme credits.

## Evidence and Limitations

The available source is one handbook page: IcfaiTech Student Handbook 2023–24, section 4.7.3, page 27. The semester credit totals and printed grand total do not reconcile with the separately listed summer internship credits. This discrepancy is documented rather than silently corrected.

The audit is preliminary. Complete syllabi, course outcomes, assessment rubrics, and institutional confirmation were not available. Job-description findings represent a small sample. All curriculum changes are proposals requiring faculty and institutional review.

AI assistance was used to generate and organise review suggestions. AI-generated content is not presented as official institutional information.
