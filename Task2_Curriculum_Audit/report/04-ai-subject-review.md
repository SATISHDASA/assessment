# AI-Assisted Subject Review

**Review date:** 24 October 2026  
**AI tool:** ChatGPT (OpenAI)  
**Purpose:** Explore how five existing subjects could be strengthened for current AI/ML industry applications.

## 1. Method

Five subjects were selected from the supplied 2023–24 handbook page. AI was used to generate suggestions for practical learning activities and emerging topics.

The outputs below are AI-generated proposals, not verified descriptions of the institution's current teaching. They were reviewed against the visible subject titles and the industry job-description comparison.

**Prompt used:**

"Suggest practical improvements to a B.Tech AI/ML Data Structures course. Connect data structures to real AI and data-processing applications. Separate foundational topics from optional modern applications."

**AI-assisted output:**
- Retain arrays, linked lists, stacks, queues, trees, graphs and hashing.
- Add practical exercises involving large datasets.
- Compare data-structure performance using runtime and memory measurements.
- Use graph representations for recommendation and search examples.
- Include implementation testing and complexity analysis.

**Human verification:**
The handbook confirms the subject title but does not list its detailed topics. The recommendations are suitable proposals for a data structures course; they are not claims that these topics are missing from the current course.

**Recommendation:** KEEP and UPDATE practical exercises.
