# Curriculum Recommendations — B.Tech CSE (AI & ML)

## 1. Purpose

These recommendations compare the subjects visible in the IcfaiTech Student Handbook 2023–24, page 27, with the skill themes identified in the industry job-description review.

They are proposals for curriculum improvement, not claims about official institutional deficiencies.

## 2. KEEP — Retain important foundations

| Subject | Reason |
|---|---|
| Linear Algebra and Higher Calculus | Mathematical foundations for machine learning and optimization |
| Probability and Statistics | Supports statistical reasoning, experimentation and model evaluation |
| Computer Programming | Essential programming foundation |
| Data Structures | Supports efficient data processing and software development |
| Design and Analysis of Algorithms | Develops problem-solving and algorithmic efficiency |
| Database Management Systems | Supports data storage, querying and retrieval |
| Artificial Intelligence | Provides core AI concepts |
| Machine Learning | Core subject for predictive modelling |
| Deep Learning | Supports neural-network-based applications |
| Data Wrangling and Visualization | Supports data preparation and communication of results |

## 3. UPDATE — Modernize practical coverage

| Existing subject | Proposed update | Reason |
|---|---|---|
| Industry Coding Practice (Python and R) | Add Git, testing, debugging, reusable code and API integration exercises | Employers expect maintainable software, not only scripts |
| Database Management Systems | Include practical SQL, query optimization and data pipelines | Strengthens data engineering foundations |
| Artificial Intelligence | Include search, planning, evaluation and responsible AI case studies | Connects theory to real-world systems |
| Machine Learning | Include cross-validation, feature engineering, explainability and model evaluation | Improves model reliability |
| Deep Learning | Include transfer learning, deployment and model efficiency exercises | Connects model development to applications |
| Web Technologies | Include REST APIs, backend integration and secure application design | Supports deployment of AI services |

## 4. REDUCE — Review duplication, not foundations

No existing subject is recommended for outright removal based on the available one-page source.

Instead:
- Review overlap between Artificial Intelligence, Soft Computing, Machine Learning and Deep Learning.
- Review whether repeated professional-skills activities can be coordinated across semesters.
- Review elective choices to ensure that specialist AI/ML topics have sufficient practical depth.

Any reduction should follow a detailed syllabus and learning-outcome comparison. Course titles alone are insufficient evidence for removing credits.

## 5. ADD — Proposed emerging skill modules

| Proposed module | Suggested coverage |
|---|---|
| MLOps and Model Deployment | Model packaging, APIs, containers, CI/CD, monitoring |
| Generative AI Applications | LLM basics, prompt evaluation, RAG and application safety |
| Responsible AI and Data Privacy | Bias, explainability, privacy, security and governance |
| Cloud and Data Engineering | Cloud fundamentals, data pipelines and scalable storage |
| Software Testing for AI Systems | Unit tests, data validation, model tests and reproducibility |

These topics could be introduced through updated laboratory work, integrated modules or electives rather than automatically creating additional compulsory credits.

## 6. Priority order

1. Add practical Git, testing and reproducibility across programming laboratories.
2. Strengthen model evaluation and explainability in Machine Learning.
3. Add API integration and deployment exercises.
4. Introduce a practical MLOps module.
5. Introduce Generative AI and RAG with safety and evaluation.
6. Integrate responsible AI, privacy and security across relevant subjects.

## 7. Overall recommendation

Retain the strong mathematics, programming, data structures, database and AI/ML foundations. Modernize laboratory exercises to include software engineering and deployment. Introduce emerging AI topics through carefully designed modules and electives, while preserving the programme's overall credit requirements and applicable regulatory approvals.

## 8. Evidence limitation

The supplied handbook page provides course titles and semester credits, not detailed syllabi or learning outcomes. Therefore, UPDATE, REDUCE and ADD decisions should be validated by faculty through a full course-level mapping before implementation.
