# Final Curriculum Audit Report

## 1. Executive Summary

This audit reviews the B.Tech in Artificial Intelligence and Machine Learning curriculum using the available IcfaiTech Student Handbook 2023–24, selected AI-related job descriptions, and an AI-assisted subject review.

The review identifies strong foundations in mathematics, programming, computer science, data science, and machine learning. It recommends modernising practical learning through model deployment, MLOps, generative AI, responsible AI, cloud and data engineering, and software testing.

The recommendations are proposals for academic review, not claims that existing subjects are inadequate or that any changes have been approved.

## 2. Scope and Evidence

The audit uses:
- IcfaiTech Student Handbook 2023–24, section 4.7.3, page 27.
- Three selected AI/data-related job descriptions documented in `02-industry-job-analysis.md`.
- AI-assisted review of five subjects documented in `04-ai-subject-review.md`.
- Proposed curriculum changes documented in `05-revised-curriculum.md`.
- Capstone proposal documented in `06-capstone-proposal.md`.

Only one handbook page was available for this review. The complete syllabus, course outcomes, detailed unit plans, and assessment rubrics were not available. Therefore, this is a preliminary curriculum audit rather than a complete institutional syllabus validation.

## 3. Curriculum Baseline and Credit Audit

The handbook page lists these semester credit totals:

| Semester | Credits |
|---|---:|
| I | 22 |
| II | 22 |

| IV | 22 |

| VII | 15 |
| VIII | 15 |

The eight semester figures add up to 159, not 161. The page separately lists a summer internship worth 3 credits. Adding that internship to the semester figures gives 162.

This creates an unresolved credit-total discrepancy. The official programme authority should confirm the correct total before any formal curriculum revision. This report does not silently reconcile the figures.

## 4. Industry Alignment

The selected job descriptions indicate demand for practical skills in:
- Python and SQL.
- Machine learning, statistics, and model evaluation.
- Data preparation, feature engineering, and visualisation.
- APIs, backend services, and software integration.
- Generative AI, retrieval-augmented generation, and model evaluation.
- Cloud platforms, deployment, monitoring, and responsible AI practices.

These job descriptions are a small sample and should not be treated as a complete representation of the job market.

## 5. Curriculum Audit Recommendations

### KEEP

Retain the foundational areas:
- Mathematics and statistics.
- Programming and data structures.
- Algorithms and database systems.
- Artificial intelligence and machine learning.
- Deep learning and data wrangling.

These subjects provide important theoretical and technical foundations.

### UPDATE

Modernise practical learning in existing subjects:
- Programming: Git, debugging, testing, and API development.
- Database systems: query optimisation and data pipelines.
- Artificial intelligence: search, planning, and responsible AI.
- Machine learning: feature engineering, validation, and explainability.
- Deep learning: transfer learning and deployment.
- Web technologies: backend integration, APIs, and security.

### REDUCE OR CONSOLIDATE

Do not remove subjects based only on their titles. Review possible overlap among Artificial Intelligence, Soft Computing, Machine Learning, and Deep Learning using their detailed syllabi and learning outcomes. Coordinate repeated professional-skills content where appropriate.

### ADD

Consider introducing or strengthening:
- MLOps and model deployment.
- Generative AI and retrieval-augmented generation.
- Responsible AI, privacy, and security.
- Cloud computing and data engineering.
- Software testing and reproducibility.

## 6. Proposed Revised Curriculum

The proposed revision uses approximately 20% of the printed 161-credit figure as a planning target: about 32 credits for modernisation and review.

The proposal identifies 12 illustrative credits for new modules:

| Proposed module | Credits |
|---|---:|
| MLOps and Model Deployment | 3 |
| Generative AI and RAG | 3 |
| Responsible AI, Privacy and Security | 2 |
| Cloud and Data Engineering | 2 |
| Software Testing and Reproducibility | 2 |
| **Total illustrative new modules** | **12** |

The remaining approximately 20 credits in the planning target would be addressed through modernising existing labs, projects, and assessments rather than automatically adding credits.

These are planning recommendations. Prerequisites, semester placement, credit allocation, faculty capacity, and regulatory requirements require institutional review.

## 8. Proposed Capstone

The proposed capstone, **AssignmentFlow: Intelligent Academic Workflow and Analytics**, extends the assignment workflow prototype into a potential academic project.

Possible features include:
- Submission tracking and status dashboards.
- Duplicate-submission detection.
- Workflow analytics and delay-risk analysis.
- Feedback-theme analysis.
- Exportable reports.

Potential AI/ML components include duplicate detection, delay-risk modelling, and feedback-text classification. Any implementation using student data must apply privacy, consent, access-control, and fairness safeguards.

The current AssignmentFlow prototype is a local demonstration. It does not establish production readiness, institutional integration, or validated predictive performance.

## 9. Limitations and Risks

- Only one handbook page was available.
- The printed credit total does not reconcile with the semester and summer-term figures.
- The selected job descriptions are a limited sample.
- Detailed subject syllabi and learning outcomes were unavailable.
- AI-assisted recommendations require faculty validation.
- Proposed new modules require academic and regulatory approval.
- Student-data analytics would require appropriate privacy and security controls.

## 10. Conclusion

The available curriculum page shows a broad foundation in mathematics, computing, AI, and data science. The recommended direction is to preserve these foundations while strengthening practical skills in deployment, generative AI, responsible AI, cloud/data engineering, and software quality.

The next step should be a faculty-led review of complete course syllabi, learning outcomes, assessment methods, credit totals, and current industry requirements before any formal curriculum changes are adopted.
