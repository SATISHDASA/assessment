# Evidence folder

Place dated, redacted screenshots or notes here. Do not add student names, IDs, marks, private messages, credentials, or identifiable register pages.

Label each item as one of:
- `OBSERVED` — directly observed by you.
- `REPORTED` — your own experience or a participant's account.
- `ESTIMATE` — a numerical estimate with its method.
- `ASSUMPTION` — a modelling assumption.
- `SYNTHETIC` — fabricated test/demo data.

Do not describe a student-reported detail as institutionally verified.
